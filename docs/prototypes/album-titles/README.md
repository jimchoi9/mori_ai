# 앨범 명칭·제목 탐색 시안 — 2026-11-03

제품 변경 전 비교 시안. 15개 가상 상황, 실제 Luna 12호출×2회 제목 결과, 별도 날짜 표시, 이름 수정/취소/자동 응답 경합을 확인한다. 사진 분석·실제 사용자 테스트·제품 API 구현이 아니다.

원본 checkout과 실제서비스는 변경하지 않는다. 결과JSON은 가상 글귀의 제목만 포함하며 개인사진·API키·request ID·실앨범자료는 없다. 시안을 바꾸거나 새로고침해도 실제 앨범에는 영향이 없다. 상태는 현재 탭 메모리이고 새로고침하면 원복한다.

## 실행

`python3 -m http.server 18214 --bind <현재 LAN IP> --directory docs/prototypes/album-titles`
현재 세션은 http://192.168.0.120:18214/ . 스크린샷용 화면은 /?preview=1 (비교 패널 숨김). 같은Wi-Fi에서상황/명칭비교·이름바꾸기·늦은자동응답보존을체험한다. `node --test docs/prototypes/album-titles/policy.test.mjs` 8검사통과.

## 실제 생성 시험

가상 기존 사진글귀만 사용, 사진/이전제목/정답제목/날짜를모델에보내지않았다. Luna1호출→title JSON, 첫지침12회와짧은경험으로묶는지침12회. 원장사용비용총USD0.0012122, unknown추가없음. 3개상황(빈앨범/사용자제목/내용단서없음)은각회차호출안함. 모델입력은cases.json/지침은scripts/experiments/album_title_research.py이며개인원장영수증은원래.local에있다.

실험결과예:기장바닷가나들이→기장나들이,삼성동식사→삼성동한끼,식당국밥한끼→국밥한끼,교토거리와사찰산책→교토나들이. 여러날일상은일상의풍경→일상의여러순간으로여전히일반적이다. 대표장소·행사단서가없으면사용자고유의도까지맞추기는어렵다. 한회차표본으로제목품질·재현성을보장하지않는다.

## 추천

내앨범(메뉴) / 짧은장소·경험제목 / 촬영기간·사진수별도 / 제목입력필수없음 / 최초선택묶음업로드·글귀준비후1회자동 / 직접이름바꾸면AI가덮어쓰지않음 / 새사진추가때도기존이름보존. 빈앨범은새앨범. 수정은앨범내부제목/연필에서만제공. 목록은앨범열기로단순화. 업로드·촬영·계정등록을중간제목입력으로막지않는다.
