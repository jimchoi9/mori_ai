# 결과 시안의 구매 진행 버튼 체험

9·10번의 대상인 결과 카드 `굿즈로 보기`를 개선하기 위한 일반 브라우저용 합성 모형이다. 기존 제품 컴포넌트/전송 버튼/생성 수명/구매 API를 수정하지 않는다.

- 구매 CTA: 사진 바로 아래 카드 폭의 녹색 `이 시안으로 구매하기`는 사용자가 이전보다 직관적이라고 평가했다. 제품 구매 동선 전체를 채택한 것으로 확대하지 않는다.
- 수정 동작의 최신 제안: 선택 전은 연필 아이콘/흰 배경/테두리의 `이 시안 수정하기` 버튼, 선택 후는 연한 초록색/체크의 `수정 대상으로 선택됨`이며 다시 누르지 않는다. 다른 시안을 고르면 이전 카드는 동작 버튼으로 돌아온다. 중복인 `현재 수정 대상` 배지는 사용자 요청으로 제거했다. 선택할 때 스크롤/커서 이동/키보드 열기를 강제하지 않는다. 입력창의 썸네일과 `시안 N 수정 중` 대상만 함께 바꾸며 입력은 사용자가 직접 시작한다. 구매 버튼과 전송 화살표는 유지한다. 최종 시각 인수는 별도다.
- 상단 선택으로 기존의 약한 `굿즈로 보기` 표시와 비교한다. 기존 모드가 재현하는 범위는 카드 버튼의 표시/강조다. 두 모드의 다음 화면은 같은 제안 화면이며 현재 운영의 전체 미리보기/저장/로그인/구매 흐름을 재현한 것이 아니다.
- 샘플 시안1·2의 각 구매 버튼은 그 시안을 별도로 선택해 `주문 내용 확인`에 전달한다. 수정 기준이1이어도 시안2를 구매 대상으로 선택할 수 있다.
- `시안 다시 고르기`는 수정 초안과 수정 기준을 보존한다. 대상 변경 때도 입력 내용을 지우거나 요청을 자동 전송하지 않는다. 기존 원형 화살표는 그대로이며 요청 체험은 새 이미지를 생성하지 않는다.
- `구매 단계로 계속`은 선택한 시안 번호가 연결됐다는 합성 안내만 표시한다. 실제 가격/결제수단/배송정보 입력, 로그인, 디자인 저장, 구매/주문/메일/AI 호출은 없다. 그림은 직접 작성한 SVG이며 개인 미디어는 사용하지 않는다. 제품 연결은 사용자 피드백 후 별도 작업이다.

현재 서버는 기존18210의 합성 폴더 안 `output/save-confidence-browser/goods-proceed/index.html` 복사본을 제공한다. 수정 시 이 복사본도 갱신한다. 원본은 단일 HTML이라 파일로 열어도 동작한다. 실행·선택 상태/실기기 검증은 `docs/개발운영.md` 최신 절에 기록한다.
