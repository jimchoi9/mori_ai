# 저장 완료 알림과 편집 버튼 체험

일반 브라우저에서 `index.html`을 열어 사용하는 합성 모형이다. 실제 사진 선택·전송·API·AI·영속 저장은 없다. 제품 결정과 원래14건의 상태는 `docs/개발운영.md` 최신 절을 따른다.

상단에서 완료 토스트 / 작은 완료 팝업 / 변경에 따라 편집 버튼 / 굿즈 첨부 상태를 선택한다. 샘플30장을 선택하고 사진 추가 후 스크롤하면 목록 위치와 무관하게 표시되는 알림을 비교할 수 있다. 처음부터 체험은 모형 상태만 초기화한다.

편집 버튼은 처음 `완료`, 글귀를 한 번 수정하면 `저장하고 완료`다. 자동저장 후에도 해당 편집을 닫을 때까지 유지한다. 실패 시 입력과 편집을 보존한다. 정상 완료 외 상황은 상단 체험 상황으로 선택한다.

로컬 실행:

```sh
python3 -m http.server 18210 --bind 127.0.0.1 --directory docs/prototypes/save-confidence
```

같은 Wi-Fi 휴대폰 체험은 합성 모형만 든 폴더를 `--bind 0.0.0.0`으로 제공한다. 저장소 전체나 개인 사진 폴더를 서버 루트로 사용하지 않는다. 작업 중인18210은 `output/save-confidence-browser`의 복사본을 제공하므로 수정 후 `index.html`을 그 폴더에 복사한다.
