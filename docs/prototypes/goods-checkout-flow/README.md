# 구매부터 사진 채우기까지의 단계 축소 체험

11~13번의 제안을 확인하는 일반 브라우저용 모형이다. 기존 제품의 구매/권한/저장/로그인 API는 변경하지 않는다. 앞서 채택한 시안 카드의 버튼·선택 상태·전송 화살표는 기존 모형에서 복사해 유지했다. 샘플 SVG도 이전 모형의 직접 작성 자료다.

- 단계를 합친 안: 시안 선택 → 구매 내용 확인 → 사진 채우기. 마그네틱의 별도 미리보기/저장 완료 페이지를 합친다. 키링의 고리 위치와 사진을 채울 사람 선택은 같은 확인 화면에 둔다. 고리 배치 그림/좌표는 체험용이며 실제 제작 유효성 검증이 아니다.
- 현재 구조 비교: 시안 선택 → 굿즈 미리보기 → 내 디자인 저장 완료·테스트 구매 → 구매 완료 → 사진 채우기. 핵심 화면/동작을 재현한 비교 모형이며 모든 실제 오류/로그인 분기까지 동일한 구현은 아니다.
- 로그인한 일반 구매 기준 모형상 진행 버튼은4회→2회다. 로그인·고리/사진관리자 선택·되돌아가기는 이 비교에서 제외하며 실제 서비스 계측이 아니다.
- 사용자 확정은 **구매 완료 안내와 함께 앨범으로 바로 이동**이다. 앨범에6초 완료 토스트와 지속 구매 상태를 표시하고 주문 내역은 앨범 안에서 다시 확인한다. 상단 추가 상황에서 완료 화면을 거치는 안도 비교할 수 있다. 단계 합치기 전체/문구는 아직 사용자 체험 후 최종 확정 대상이다.
- `디자인만 저장`은 같은 확인 화면에서 저장 상태/토스트만 표시한다. 비회원은 샘플 로그인 뒤 선택 디자인/고리/사진관리자 선택을 보존한다. 구매는 로그인 후 확인 화면에서 다시 명시적으로 진행한다.
- 받는 사람이 사진을 채우는 선물은 구매자의 앨범으로 바로 보내지 않는다. 등록 안내를 보여주고 상단의 `선물받는 분의 등록 화면 체험`으로 명시 등록을 체험한다. 모형에 실제 QR/인증/양도 권한은 없다.
- 사진 추가도 합성 SVG 묶음을 추가하는 예시다. 실제 파일 선택·전송·영속 저장·결제·주문·로그인·AI·메일은 없다. 상단 설정 변경/처음부터 체험은 모형을 초기화한다.

기존18210 서버의 `output/save-confidence-browser/goods-checkout-flow/`에4개 파일을 복사해 제공한다. 실행은 HTTP 정적 서버가 필요하며 HTML 파일 직접 열기는 ES module 제약이 있다. JS구문/제공본문 일치 검사를 했고 실제 브라우저 조작은 완료하지 못했다. 세부 검증·제한과 사용자 결정은 `docs/개발운영.md` 최신 절을 따른다.
