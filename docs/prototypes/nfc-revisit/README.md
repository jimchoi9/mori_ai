# 실제 프론트엔드로 재방문 체험

같은Wi-Fi http://192.168.0.120:18214/ /Mac http://127.0.0.1:18214/ .Mac과체험프로세스가실행중이어야한다. 기존2시간선택형가상모형을대체하는현재결과다.

현재Docker frontend이미지의/build/dist를output/nfc-revisit-live로복사하고기존가상group-synthetic.jpg를_demo-group.jpg로복사한다. server.py --root <전용폴더> --bind 0.0.0.0 --port 18214로실행한다. 일반운영API/DB/계정/개인사진/AI/메일에접속하지않는다. 실제컴파일된React/NFC코드가표시되며가상HTTP어댑터만다르다.

기본감상화면에는QA버튼/설명을띄우지않는다. 테스트용글수정이필요하면주소의?tools=1로별도QA오버레이를명시해열고수정후브라우저reload로확인한다. 제품에는상시최신보기/새로고침버튼이없다. 현재주소를북마크/새탭으로열어도다시감상할수있다. 가상키/전송grant만쓰며저장/주소유지로직은현재제품의것을그대로쓴다. BGM은이체험에서생략한다. 이체험서버의2시간전송grant는실서버와같은형태지만고객감상강제종료를뜻하지않는다.

HTTPscript200/가상enter/사진동일/글수정후새snapshot/close204/LAN200과제품frontend306검사/타입/Vite를확인했다. 브라우저연결오류로실제자동클릭/스크린샷/휴대폰수용인수는미완료다. 실제NFC/운영인수로확대하지않는다.
