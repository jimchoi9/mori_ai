# 사진 채우기와 자르기 한도 비교

v2는세로~1:1 cover/1:1~4:3 부드러운전환/4:3이상한쪽최대5%가초기제안이다.1:1경계에서바로고정5%상한으로바꾸던v1을대체한다. 전환끝점4:3은사용자확정전이며정사각근처는꽉채움을우선해5%보다많이잘릴수있다. 넓은사진도화면영역과비율이맞으면반드시5%를자르지는않는다.

geometry.mjs에서cover로채우는데필요한자름량과넓은사진상한을smoothstep으로보간한다. 실제책사진영역의비율도함께계산한다. 기본가로상한은총10%(한쪽5%)이며설정에서5/10/15%씩을비교할수있다. 얼굴검출/원본사진편집은없다.

기존St.PageFlip/book.js/현재nfc.css를그대로실행폴더로복사해사용하고추가CSS와이미지배율만바꾼다.75/25영역과제스처유지,확대/BGM/제품권한연결없음. 가로는 `min(cover,contain/(1-crop))`배율을쓰며최대에먼저도달하면여백은흐린배경으로남는다. 소스는독립geometry.mjs에둔다.

실행폴더는output/save-confidence-browser/photo-fill이다. 이4파일과기존책/라이브러리/MIT고지/nfc.css를복사하고앞서생성한wide-photo/assets/group-synthetic.jpg를sample.jpg로복사한다. 새사진생성이나개인사진공유는없다. 휴대폰주소는http://192.168.0.120:18210/photo-fill/이고같은Wi-Fi/Mac실행이필요하다. 내사진선택은기기blob URL만사용하고서버전송하지않는다.

배치수학/상한/여러비율/HTTP제공/구문은확인했다. 실제기기렌더·넘김·얼굴잘림판정과사용자한도선택은별도다. 제품코드는이전contain+blur가남아있으며이번모형으로가로한도를확정한뒤반영한다.
