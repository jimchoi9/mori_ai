# 굿즈 사진 첨부 상태 체험

7a번의 문구와 다음 행동을 확인하는 단일 HTML 모형이다. 기존 굿즈 화면의 종이색/초록색/입력창 배치를 참고했고 샘플 SVG는 직접 작성했다. 제품 화면·첨부 정책·API는 변경하지 않는다. 전송 버튼은 기존 원형 화살표이며 사용자가 개선을 요구한 대상은 결과 카드의 `굿즈로 보기`다. 해당 버튼의 진행 의미/강조는 별도 후속 대상으로 기록한다.

- `사진 첨부` → 준비 → 첨부 중 → 썸네일과 `사진 첨부 완료` → 기존 원형 화살표 전송 버튼을 직접 누른다.
- 상단에서 정상 / 첨부 한 번 실패 후 재시도 / 느린 첨부를 고른다. 상황 변경과 처음부터 체험은 모형을 초기화한다.
- 설명 입력은 첨부 중/실패/재시도에도 보존한다. 사진 없이 설명만으로 시작하는 기존 선택지도 유지한다.
- 사진 바꾸기 실패는 기존 첨부를 남기고, 실패 항목을 재시도하거나 취소한 후 진행한다. 최종 UX는 사용자 피드백 후 확정한다.
- 시안은 고정된 샘플 SVG다. 개인 파일 선택·서버 전송·AI 호출·영속 저장·디자인 구매는 실행하지 않는다. 생성 소요 시간도 합성이다.

`index.html`을 일반 브라우저에서 열거나 이 폴더만 정적 서버로 제공한다. 현재는 기존18210 서버의 `output/save-confidence-browser/goods-attachment/index.html`에 복사해 제공한다. 변경 후 이 복사본도 갱신한다. 코드 검사는 스크립트 추출 후 `node --check`, 제공 내용 검사는 HTTP 응답과 원본 비교로 확인한다. 제품279검사에 모형 검사를 합산하지 않는다.
