# NFC 최신내용과 브라우저 새로고침 체험

http://192.168.0.120:18210/nfc-update/ (같은Wi-Fi/Mac실행필요),Mac은127.0.0.1동일경로다. 실제NFC/계정/개인사진과연결하지않은합성권한·가상사진모형이다. 최신내용보기는예시글만바꾼다.

1. NFC태그상황으로시작한다.
2. 감상메뉴에서관리수정상황을만들고최신내용보기를누른다.
3. 같은탭이어보기/화면안에서만두설정을각각고른뒤브라우저새로고침체험을누른다.
4. 연결실패를켜고다시최신보기를눌러기존책유지를확인한다.

첫안은합성expiresAt만sessionStorage에두고갱신시시간을연장하지않는다. 두번째안은합성grant도메모리에만둔다. 실제NFC비밀/쿠키/권한/제품API변경은없으며최종정책은사용자질문답변대기다.

실행폴더에는이3파일/기존book.js/page-flip.js/MIT고지/nfc.css를복사한다. 기존../wide-photo/assets/group-synthetic.jpg와../photo-fill/geometry.mjs?v=2를사용한다. JS구문/HTTP제공검사는완료했지만실제브라우저조작/기기권한수명인수는미완료다.700ms는모형에서확인중상태를보여주기위한지연이다.
