# 사진을 담지 않은 새 앨범을 남기지 않는 체험

새 앨범을 누르면 사진 관리 화면을 먼저 보여준다. 사진 추가를 눌러야 선택 화면이 열린다. 예시 선택을 취소하면 관리 화면에 머물고, 사진을 추가하지 않은 채 목록으로 나가면 새 앨범은 남지 않는다. 예시 사진을 추가한 뒤에는 목록에 남는다.

기존 책장 CSS·책 라이브러리와 개인 정보 없는 도형 예시 이미지를 사용한다. `index.html`과 `preview.js`를 Git에서 제외된 `output/album-start-discard-review`에 복사하고 기존 비교 서버의 고정 허용 파일 목록을 사용한다. 서버는 지정한 LAN 주소에만 바인딩한다. 개인 사진은 제공하지 않는다.

탭 메모리의 모형이며 제품 API·업로드·AI·DB·삭제 요청은 없다. 예시 사진 선택 화면은 휴대폰 기본 선택기가 아니다. 새로고침하면 예시도 초기화된다. 제품의 전송 중/실패/응답 유실/다른 탭/브라우저 종료 처리는 이 체험의 검증 범위가 아니다. 제품 연결 시 사진 저장 이력이 있는 기존·구매 앨범을 빈 앨범이라는 이유로 삭제하지 않아야 하며, 선택·전송·재시도 중인 작업을 보호해야 한다.
