# 앨범 삭제 보호 체험

실제 기능에 연결하기 전에 사용자가 최종 확인 방식을 고르는 안전한 체험이다. 첫 화면에 실제 앨범이 삭제되지 않는다고 표시한다. 모든 앨범 이름·수량·굿즈 연결은 예시이고 표지는 개인 자료 없는 도형 WebP다.

공통 흐름은 더보기→앨범 설정→앨범 삭제→대상 표지/이름/사진 수와 영향 확인이다. 체크박스 확인과 ‘삭제’ 직접 입력만 비교한다. 마지막 버튼은 조건 충족 전 비활성이고 취소/닫기/Escape/배경 클릭은 삭제하지 않는다. 확인 입력칸 Enter는 삭제를 실행하지 않는다. 입력칸을 자동 포커스해 키보드를 강제로 열지 않으며, 모달의 기본 포커스는 취소/닫기다. 다시 열거나 방식을 바꾸면 확인 상태가 초기화된다.

실제 삭제 API·AI·로그인·업로드·DB·storage는 사용하지 않는다. 마지막 버튼은 탭 메모리의 예시 목록에서만 숨기며 예시 초기화/새로고침으로 돌아온다. 이 동작을 제품 휴지통/복구 정책으로 약속하지 않는다. 현재 제품에 사용자 복구 API는 없고, 삭제는 앨범 상태와 감상 접근에 영향을 주므로 실제 연결은 별도 검증한다.

소스의 index/preview CSS/JS를 gitignore된 output/album-delete-protection-review에 복사한다. 기존 앨범 시작 체험의 합성 표지(각3KB 미만)·공통 CSS/기존 제품 책장 CSS만 사용한다. 기존 album-home-review/server.py의 고정 허용 목록·특정 LAN 바인딩·개인 prefix·no-store/CSP connect none으로 제공한다. 서비스/개인 앨범에는 영향을 주지 않는다.
