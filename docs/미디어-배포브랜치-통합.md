## 2026-10-20 굿즈 MPO 업로드 수정

JPG 확장자 안에 보조 프레임이 있는 MPO를 굿즈 사전 검사에서 거부해 415가 발생했다. 앨범 v2 코덱은 이미 주 프레임을 처리하지만 굿즈의 허용 형식 및 다중 프레임 검사에 MPO가 빠져 있었다. 두 검사에서 MPO를 기존 HEIF처럼 주 이미지 처리 경로로 전달한다. PNG/WebP 애니메이션 거부와 코덱의 HDR·10bit 제한은 유지한다. API·DB·예약·생성 슬롯 설정 변경은 없다.

첨부 원본은 로컬의 네트워크 없는 컨테이너에서만 검증하고 저장소에 포함하지 않았다. 실제 굿즈 스트림 입력 → 사전 검사 자식 프로세스 → v2 정규화 자식 프로세스 결과는 2048×1536 단일 WebP, 517,362바이트이며 EXIF가 제거됐다. 합성 MPO로 수정 전 415 실패를 재현한 뒤 주 프레임 색상·EXIF 방향 보정 및 HDR 거부를 검증했다. APNG 거부도 회귀 검사에 추가했다. 굿즈 미디어 테스트 21개가 통과했다. 전체 회귀 및 통합 커밋은 완료 보고를 따른다. 서버 배포는 사용자가 수행한다.
