# Mori AI 사진첩 프로젝트

사진을 올리면 AI가 세로 3:4 이미지와 한 문장 글귀를 만들고, 사용자가 글귀를 수정해 모바일 사진첩으로 감상하는 서비스다. 초기 범위는 책장·사진 입력·생성·수정·뷰어이며 Google/Kakao 로그인과 HEIF/HEIC 입력·서버 WebP 정규화를 포함한다.

2026-10-16 사용자가 순차 진행을 승인했다. 기술 시작 기준과 계약 v1.3을 반영했고 첫 개발 묶음 실행 계획을 검토하는 단계다. 제품 코드·설치·배포·외부 연동 성공을 기록한 상태가 아니다. GPT Image 2의 사진 변환 품질은 사용자가 확인했으며 실제 서비스 계정의 시간·비용·오류 복구·codec는 별도 검증한다.

에이전트의 작업 규칙은 [AGENTS.md](AGENTS.md)를 따른다. 현재 사용자 지시와 확정 요구가 우선하며 구현 계약은 공통계약과 샘플이 기준이다. 설계의 기술 시작 기준과 계약 보완 5개는 2026-10-16 채택했다. 이후 추가 제안은 채택 전까지 현재 계약을 대체하지 않는다. 문서를 정리한 것은 구현·기술 승인·검증 완료를 뜻하지 않는다.

## 어디에 기록하는가

- 기능 범위·과제 조건은 기능요구명세서에 기록한다.
- API·DTO·상태 변경은 공통계약과 샘플을 함께 수정한다.
- 화면·기술·성능 설정 제안은 설계에 기록하고 확정 여부를 표시한다.
- 원본 코드 출처·채택·이식 내역은 재사용조사에 기록한다.
- 미결정 D 항목과 검증 A/F/V 결과는 검증계획에 기록한다.
- Task 배정·환경 격리·일정·통합 상태는 개발운영에 기록한다.

현재 V01~V10은 미실행이고 make verify-*는 기반 작업에서 만들 명령 제안이다. 실제 실행 절차는 코드 기반을 마련한 뒤 이 README에 추가한다. 기존 moriai의 명령·운영 계정·DB·파일은 새 프로젝트의 실행 자원으로 사용하지 않는다.

[실행 계획](docs/superpowers/plans/2026-10-16-development-foundation.md)은 최소 기반 V01 후 미디어 V02/V09와 DB·worker V03/V04를 병렬 검증하는 범위다. 2026-10-16 기술 시작 기준·계약 v1.3 반영 완료. 실행 계획 검토 전이며 제품 코드·의존성 설치·외부 연동은 아직 완료하지 않았다. 기준 커밋에는 현재 문서와 계약을 포함하고 원본 PDF·UI 참고 파일은 별도로 유지한다.
